# 统一测试场

正式交互测试入口为 `res://scenes/test_arena.tscn`，启动配置和运行时 Boot 均指向该场景。旧的 `tests/character/test_arena.tscn` 与独立墙体交互场景已经移除，自动化墙体测试仍保留为独立测试脚本。

场景包含：

- 玩家、稳定地面和像素摄影机；
- 五个未堕道具拾取台，接触后进入玩家 `MudItemInventory`；
- 两面可扒墙、滑墙、蹬墙的训练墙和顶部平台；
- 不会死亡、记录命中次数的训练假人；
- 使用完整 MudCharacter、武器、Hurtbox、受击、死亡和评分资料的 AI 敌人生成器；
- 调试 HUD、道具卡画廊、评分面板和人群性能测试。

操作：`A/D` 移动，`Shift` 跑，`Space` 跳跃/蹬墙，`J` 或鼠标左键攻击，`F3` 生成真实敌人，`F6` 查看五张道具卡，`R` 重置玩家和道具拾取台。
